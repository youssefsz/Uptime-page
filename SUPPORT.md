# Support

## Usage and setup

Start with the [README](README.md), especially the quick-start, configuration, and deployment sections. Check existing [issues](https://github.com/youssefsz/Uptime-page/issues) for known problems and established workarounds.

If you still need help, open a GitHub issue and include:

- What you are trying to do
- The Uptime Page commit or version
- Operating system, Python version, and installation method
- Relevant logs and the exact error message
- Troubleshooting steps you already tried

Remove access tokens, passwords, connection strings, private hostnames, and other sensitive data before posting.

## Bugs and feature requests

Use the repository's bug-report or feature-request form. A minimal reproduction makes bugs substantially easier to diagnose. Feature proposals should explain the problem and who benefits from solving it.

## Security

Do not open a public support request for a suspected vulnerability. Follow [SECURITY.md](SECURITY.md) to report it privately.

Support is provided by project maintainers and contributors on a best-effort basis; response times are not guaranteed.
